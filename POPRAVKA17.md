ПОПРАВКА 17 к PREREGISTRATION.md — аннулирование дефектной подстановки в POPRAVKA13.md и правило подстановки значений в замороженные документы

Статус: проект к заморозке. Настоящая поправка не изменяет методику: она аннулирует ошибочные коммиты, восстанавливает действующую редакцию ПОПРАВКИ 13 и фиксирует правило подстановки значений на будущее. Процедура заморозки — двухкоммитная, как в ПОПРАВКЕ 16.

Контекст
ПОПРАВКА 13 была заморожена коммитами 9bc9431 -> 64caf2e: файл 46581 байт, SHA256 C2ACD43CD025CFB342728ED46C8E64C47A9BD30EABA8D5EE56EDC7C377600963, 325 строк, заглушек ноль. Позже другой исполнитель, не зная о состоявшейся заморозке, взял устаревшую редакцию файла (33676 байт), подставил в неё числа и закоммитил поверх: d7c0b34 -> 102e865; результат на диске — 33522 байта. Подстановка содержит два независимых дефекта (§1).

§1. Аннулирование коммитов d7c0b34 и 102e865 (в части POPRAVKA13.md)
Коммиты d7c0b34 и 102e865 объявляются НЕДЕЙСТВИТЕЛЬНЫМИ в части POPRAVKA13.md по двум независимым причинам.

Дефект 1 — взята не та колонка развёртки. Решение по N_min принято и обосновано в самой ПОПРАВКЕ 13 (§1.4 и Приложение А): порог упразднён, N_min = 1. Действующие значения — 0.005000, 1.011292832, 130719, 247522 (см. §3). Вместо них подставлены 0.005000, 1.000000, 5189, 418857 — это строка Приложения А для N_min = 20 (12779 измеримых, 1210 решающих, p90 ATP 0.04957 при n = 9317, p90 WTA 0.05107 при n = 3462, M* = 5189, ratio = 1), за исключением 418857, происхождение которого неизвестно и который был приравнен к n_band, отчего отношение и вышло единицей. Строка 322 самой ПОПРАВКИ 13 объявляет ratio = 1 при N_min из {10, 20} вырожденным: §4.4b на этих порогах непроваливаем ни при каких данных, то есть подставленная четвёрка делает тест §4.4b тавтологически проходимым.

Дефект 2 — слепая подстановка в формулировки решающих правил. Подстановка заменила имена величин числами не только в отчётной части, но и в текстах решающих правил. Примеры испорченных строк:
- «если 1.000000 > 1.5 ⇒ оценщик признаётся забитым дрейфом»;
- «при 5189 < 200 пар тест немощен»;
- «ЕСЛИ 418857 == 0 ⇒ STOP».
Условия превратились в тавтологии (константа против константы) и стали неприменимы к любому будущему прогону: правило больше не сравнивает результат прогона с порогом, а сравнивает два зафиксированных числа.

§2. Действующая редакция ПОПРАВКИ 13
Действующей редакцией POPRAVKA13.md является редакция 64caf2e (46581 байт, SHA256 C2ACD43CD025CFB342728ED46C8E64C47A9BD30EABA8D5EE56EDC7C377600963, 325 строк, заглушек ноль), восстановленная коммитом восстановления с хешем 675d973 (вписывается после пуша). Коммиты d7c0b34 и 102e865 в части POPRAVKA13.md силы не имеют; при любом расхождении на диске авторитетна редакция 64caf2e, подтверждаемая указанным SHA256.

§3. Действующая четвёрка значений §4.4 и источник каждого
Все четыре значения — из решения N_min = 1, принятого в §1.4 ПОПРАВКИ 13 и обоснованного развёрткой Приложения А (строка N_min = 1):
- N_4_4A = 0.005000 — медиана spread_cost_point по измеримым парам при N_min = 1 (§4.4a; Приложение А, строка N_min = 1).
- N_4_4B = 1.011292832 — отношение median(spread_60) / median(spread_10) при N_min = 1 (§4.4b; Приложение А, строка N_min = 1); значение отлично от вырожденной единицы, поэтому тест содержателен.
- M_STAR = 130719 — |M*|, число решающих пар при N_min = 1 (§4.4b; Приложение А, строка N_min = 1).
- N_POOL_DIFF = 247522 — n_pool_diff, число пар с непустой полосой между окнами (P_{w,m}(10) ⊊ P_{w,m}(60)), измеренное проверкой §4.4-guard (247522 == 247522, guard пройден).

§4. Правило подстановки значений в замороженные документы (на будущее)
1) Подстановка значений в замороженный документ допускается ТОЛЬКО в отчётные строки и ТОЛЬКО по списку из чек-листа в конце документа.
2) Имена величин в формулировках решающих правил подстановке НЕ подлежат: в правиле остаётся символьное имя (например, «отношение», n_pool_diff, |M*|, N_min), а числовой результат прогона заносится в отдельную отчётную строку.
3) Перед подстановкой обязательна сверка размера и SHA256 исходного файла с последней заморозкой; при несовпадении — СТОП, подстановка не выполняется.
