# ПОПРАВКА 11 — терминальные цены внутри предматчевого окна

Дата заморозки: 2026-08-04 ; Коммит-хеш: a2480ef
Основание: прогон окна [2026-02-01 00:00Z, 2026-04-28 00:00Z), справочный счётчик DOBAVKA3.

## §1. Факт
Справочный счётчик [term] дал 209 предматчевых сделок с ценой >= 0.999 или <= 0.001 при печатном ожидании 0.
Измерение стороны эталона выполнено только на чтение по артефактам принятого прогона окна: действительных пар с p_ref по терминальной цене — 0 из 440848 (ATP 0 из 307151, WTA 0 из 133697). Затронутых рынков — 0. Медианный возраст и разбивка >= 0.999 / <= 0.001 — нет данных: мерить нечего.

## §2. Правило для эталона p_ref
p_ref не может быть взят со сделки, цена которой после приведения к T* через комплемент (§2 П7) >= 0.999 или <= 0.001. Такая сделка пропускается; эталоном становится следующая ближайшая сделка строго до gameStartTime в пределах допустимого возраста 60 минут; если такой сделки нет — пара недействительна по строке 3 воронки («нет эталона <= 60 мин»).
На окне [2026-02-01, 2026-04-28) правило является профилактическим no-op: 0 затронутых пар, 0 рынков. Пересчёт окна не требуется.

## §3. Сторона входа — открытый пункт, блокирует Этап 4
entry_vwap терминальность не фильтрует (проверяется только 0 <= price <= 1), поэтому терминальная предматчевая сделка попадает во вход. До начала статистики Этапа 4 обязательно измерить по сырым /trades:
(а) доля действительных пар, во вход которых входит >= 1 терминальная предматчевая сделка;
(б) доля пар, где такие сделки дают > 50% объёма входа;
(в) максимальная доля затронутых пар внутри одного рынка;
(г) разбивка >= 0.999 против <= 0.001.

## §4. Решающее правило объявлено ДО получения данных §3
(а) затронуто < 0.5% действительных пар И ни один рынок не даёт >= 2% — терминальные сделки исключаются из entry_vwap правилом, пересчитываются только затронутые пары, окно не перезапускается;
(б) затронуто >= 0.5% ИЛИ хотя бы один рынок >= 2% — окно пересчитывается после исправления определения входа.
Решение принимает координатор, не исполнитель.

Расширять или ослаблять терминальный порог 0.999/0.001; применять правило §2 постфактум к уже посчитанным CLV без пересчёта затронутых пар; трактовать нулевой результат §1 как доказательство безвредности 209 сделок на стороне входа.
