# Интерфейс терминала

У терминала один пользователь, и он принимает по его числам денежные
решения. Поэтому главное требование — не красота, а невозможность
обмануться.

## Три правила, которые важнее всего остального

**1. Возраст данных всегда на экране.**
Рядом с любой ценой — `book_age_ms`. Старше порога — число сереет
или краснеет. Зависший вебсокет, показывающий старую цену как свежую,
— главный способ потерять деньги на собственном терминале.

**2. Неопределённость никогда не схлопывается в одно число.**
Если базис комиссии `unknown`, показывай вилку «от — до» и подпись
«базис не установлен». Середина вилки крупным шрифтом — ложь.
То же для любой оценки: рядом со средним всегда стоит ошибка.

**3. Пропуски видны.**
На графиках интервалы из `gap_intervals` — это разрыв линии или серая
заливка, никогда не прямая линия между соседними точками.
Соединённая линия через дыру изображает движение, которого мы не видели.

## Обязательные экраны

1. Живая книга: спред, глубина, возраст данных.
2. Калькулятор издержек: только через `cost()`, своих формул нет.
3. Мои позиции из ончейн-данных, с отдельной пометкой незабранных
   разрешённых позиций — это лежачие без дела деньги.
4. Здоровье сбора: водяные знаки, последние пропуски, ошибки
   переподключения. Без этого экрана нельзя доверять остальным трём.

## Технические правила streamlit

- Чтение данных — через `@st.cache_data` с явным TTL. Без кэша
  каждый клик перечитывает parquet целиком.
- TTL кэша НИКОГДА не больше порога свежести, показанного на экране.
- Тяжёлые агрегации — в duckdb, не в pandas поверх всего датасета.
- Не держать вебсокет внутри streamlit-процесса. Сборщик — отдельный
  сервис systemd, терминал только читает файлы.
- Не добавлять React, Next.js, свой бэкенд или библиотеки компонентов.
  Один пользователь, один VPS.

## Алерты

- Каждый алерт несёт время события И время отправки. Разница между
  ними — твоя реальная задержка, и она нужна в Этапе 5.
- Дедупликация обязательна: одно событие — одно сообщение.
  Терминал, приславший 40 одинаковых алертов, будет отключён и бесполезен.
- Токен бота только из `.env`, никогда в коде и никогда в логах.

## Чего не делать

- Не рисовать сигналы «купить/продать». Вердикт ещё не вынесен.
- Не показывать рейтинг трейдеров по сырому PnL. Только со сжатием
  и только с числом матчей рядом.
- Не прятать неудобные метрики в раскрываемые секции.
