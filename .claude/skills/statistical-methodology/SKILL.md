# Контроль методологии

Ошибка в методологии не падает с исключением, а тихо возвращает красивое
неправильное число. Пройди чек-лист перед словом «готово».

## 1. Единица наблюдения

Единица наблюдения объявляется явно и одна на весь анализ. Множество
действий одного субъекта внутри одного события дают ОДНО наблюдение, а не
много. Красный флаг: группировка по субъекту без предварительной свёртки по
событию.

## 2. Ошибки только кластерные

Если наблюдения группируются (по событию, по дню, по субъекту, по
источнику), стандартная ошибка обязана быть кластерной. Наивная
`std/sqrt(n)` занижает её в разы.

Уровни кластеризации перечисли явно, включая неочевидный: наблюдения одного
дня/турнира/релиза/новости не независимы. Если две спецификации дают разный
ответ — берётся КОНСЕРВАТИВНАЯ, без обсуждения. Оставшиеся неучтёнными
источники корреляции запиши как открытый риск.

## 3. Ранжирование

Ранжируй по сжатой (усечённой к среднему) оценке, а не по сырому
внутривыборочному результату. Отчёт обязан содержать степень сжатия. Если
сжатие близко к максимуму — данные ничего не говорят, и это надо сказать
вслух.

## 4. Множественные сравнения

Поправка на множественность обязательна, и число гипотез равно числу
проверенных кандидатов, а не числу финалистов. Занизить число гипотез — самый
тихий способ получить ложное открытие.

## 5. Решающее правило

Правило записывается формулой один раз, в одном месте кода, и вызывается
оттуда. Не дублируй логику решения. Порог не меняется после того, как виден
результат. Исход «неразрешимо» проверяется ПЕРВЫМ: если ширина
неопределённости больше измеряемого эффекта, ответа нет.

## 6. Издержки и константы

Все числовые константы (тарифы, ставки, пороги) живут в одном модуле.
Проверяй поиском, что литералов нет в остальном коде. Если основание расчёта
не установлено — код ПАДАЕТ, а не угадывает. Стандартная ошибка издержек
никогда не равна нулю.

## 7. Запрещённые движения

- подкручивание порога после того, как увидел результат;
- выбор удобного края вилки;
- замена кластерной ошибки на обычную «для простоты»;
- отбор субъектов из витрины лучших вместо всей популяции;
- замалчивание доли выброшенных наблюдений;
- вывод по подвыборке, размер которой не заявлен заранее.

Если считаешь правило неверным — скажи один раз и продолжай работать по нему.
Критерии заморожены до измерения специально.
