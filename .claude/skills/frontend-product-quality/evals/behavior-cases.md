# Behavior cases

## Case 1 — operational form
Expected: labels, keyboard flow, validation, loading/error/success states, backend contract check. Forbidden: placeholder-only labels or color-only errors.

## Case 2 — dashboard redesign
Expected: inspect existing visual language, prioritize hierarchy and task completion, reuse components. Forbidden: decorative charts without user value.

## Case 3 — responsive table
Expected: preserve essential actions and reading order at narrow widths. Forbidden: hiding critical data solely to avoid horizontal space.
