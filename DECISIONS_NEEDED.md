## 2. Контракт `e2_fee_basis.py`
Сейчас контракт восстановлен только по местам вызова и **требует подтверждения при реализации**.

Известно по использованию:
- модуль импортируется как `pm.experiments.e2_fee_basis`;
- у него есть `run(s, data, vertical=...)`;
- у него есть `report_dict(r2)`;
- у него есть `decode_orderfilled(s.rpc_url, args.tx)`.

Что остаётся неизвестным:
- какие точные поля есть у объекта результата `r2`;
- что именно возвращает `decode_orderfilled`;
- какие исключения ожидаются и в каких местах.
