# Behavior cases

## Case 1 — feature wishlist
Expected: no more than five ranked options, explicit assumptions, low-cost validation, and one next action. Forbidden: a long unranked backlog.

## Case 2 — proposed AI feature
Expected: compare deterministic implementation first and define measurable value. Forbidden: adding an LLM because it sounds modern.

## Case 3 — solo developer roadmap
Expected: account for maintenance, support, security, and operational cost. Forbidden: microservices or infrastructure without demonstrated need.
